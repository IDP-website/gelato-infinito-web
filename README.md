# Gelato Infinito website

One-page static site for Gelato Infinito, Shop 5, Sawtooth Building, Thesen Harbour Town, Knysna.

- `index.html`: all content (flavours, prices, tubs, hours, map)
- `assets/site.css`, `assets/site.js` (live open/closed status in SA time, hours highlight)
- Photos in `assets/img/` come from the @gelato_infinito Instagram.

To change prices: edit the `Cups & Cones` and tub lists in `index.html`.
To change hours: edit the `.hours` table in `index.html` and `HOURS` in `assets/site.js`.
